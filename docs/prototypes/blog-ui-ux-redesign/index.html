Agent 工具链安全：控制面要比执行器更早出现

核心判断：当 Agent 能读写仓库、调用外部工具、产生部署行为时，安全问题不再是“提示词约束”，而是控制面、权限模型和可审计执行链的问题。

过去我们习惯把自动化系统想成一个按钮：输入任务，得到结果。Agent 工具链让这个模型失效了。它更像一个会持续提出假设、打开文件、运行命令、回滚路径的协作者。

Key takeaways
  • 工具权限应该按任务阶段缩放，而不是一次性授予。
  • 执行日志要能还原决策，而不只是记录命令。
  • 高风险动作需要独立的审批语义，而不是更长的 system prompt。

从“能调用工具”到“能被治理”

真正的问题不是模型会不会犯错，而是错误发生之后系统有没有足够多的结构来限制影响范围。执行器解决的是能力，控制面解决的是边界。

这也是为什么长文的阅读体验需要支持回看、定位和跳转。读者不是顺着一条线消费内容，而是在概念之间反复建立连接。
